# Achievement photos

Drop a photo in here with the exact filename below and it will automatically
replace the placeholder icon for that achievement on the homepage -- no other
changes needed. Any common image format works (`.jpg`, `.jpeg`, `.png`,
`.webp`); just keep the filename (before the extension) the same and update
the extension in `index.html` if it's not `.jpg`.

Square photos (1:1 ratio) look best, since the placeholder box is a square.
