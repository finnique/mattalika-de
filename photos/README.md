# Photos

Drop a photo in here with the exact filename below and it will automatically
replace the placeholder icon in that spot -- no other changes needed. Any
common image format works (`.jpg`, `.jpeg`, `.png`, `.webp`); just keep the
filename (before the extension) the same and update the extension in the
HTML if it's not `.jpg`.

| File              | Where it's used                                    |
| ----------------- | --------------------------------------------------- |
| `profile.jpg`      | Hero profile picture on the home page (circular)     |
| `masters.jpg`      | Achievement: M.Sc. in Computational Linguistics (Stuttgart) |
| `tutor.jpg`        | Achievement: Tutor, IMS (Stuttgart)                  |
| `zenshu.jpg`       | Achievement: Japanese Translator, Zenshu Publishing  |
| `sap.jpg`          | Achievement: SAP Consultant, Japan System Techniques |
| `bachelor.jpg`     | Achievement: B.A. in Japanese, Chulalongkorn University |
| `luckpim.jpg`      | Achievement: Japanese Translator, Luckpim Publishing |
| `mext.jpg`         | Achievement: MEXT Scholarship, Chiba University      |

**Profile photo**: square (1:1 ratio) works best -- it's cropped into a
circle, so keep your face centered in the frame.

Achievement photos are also square, matching their square placeholder
boxes.

If a file isn't present, the emoji placeholder box just keeps showing --
nothing breaks.
