# mattalika.de

Personal portfolio site, hosted on GitHub Pages at [mattalika.de](https://mattalika.de).

## Local preview

Just open `index.html` in a browser, or serve the folder with any static file server.

## Deployment

This repo is served directly via GitHub Pages. Pushing to `main` updates the live site.
Custom domain is configured via the `CNAME` file and DNS records at the domain registrar.
